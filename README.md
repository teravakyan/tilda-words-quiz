# Квиз «Кто тут главный тиньдолог?»

Мобильный семейный квиз на знание слов Тильды.

## Что внутри

- 23 вопроса с одинаковым максимумом для всех игроков;
- крупные кнопки, звуковые реакции, серии правильных ответов и конфетти;
- итоговые звания и разбор ошибок;
- семейный рейтинг: сначала по счёту, при ничьей — по времени;
- локальное сохранение результатов и готовое подключение общего рейтинга через Google Forms/Sheets.

Слова без подтверждённой расшифровки (`Байя`, `Нюм`, `Бать`) не включены.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический веб-сервер из этой папки.

Облачные адреса и идентификаторы полей задаются в `config.js`.
